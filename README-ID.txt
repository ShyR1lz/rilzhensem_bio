WEBSITE CREATOR SHYRILZ
=======================

Isi folder:
- index.html          Struktur website one-page
- style.css           Desain blue cyberpunk, responsif PC/HP
- script.js           Identitas dan semua tautan
- assets/favicon.svg  Ikon tab browser

CARA MEMBUKA DI VS CODE:
1. Ekstrak ZIP.
2. Buka VS Code > File > Open Folder.
3. Pilih folder shyrilz-streamer-website.
4. Edit script.js, simpan Ctrl+S.
5. Buka index.html di browser untuk preview.

CARA MENGUBAH DATA:
Buka script.js lalu edit bagian CONFIG. Untuk avatar lokal, taruh file gambar di folder assets (contoh assets/avatar.png), lalu isi AVATAR_IMAGE dengan "assets/avatar.png".

DEPLOY GRATIS KE CLOUDFLARE PAGES:
1. Buka https://dash.cloudflare.com/ lalu masuk/daftar.
2. Buka Workers & Pages > Create application/project.
3. Pilih Pages dan metode Direct Upload / Drag and drop (nama menu dapat berubah).
4. Upload isi folder project (index.html, style.css, script.js, assets) atau ZIP sesuai arahan dashboard.
5. Klik Deploy dan buka URL *.pages.dev yang diberikan.
6. Cek semua tombol/link dari HP dan PC.

Website statis ini tidak membutuhkan Python, Node.js, atau proses build.
